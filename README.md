## 配置单上的五样东西，最容易拖后腿的是带宽

买云服务器时填的那张表，无非 CPU、内存、带宽、系统盘、计费方式五项，其中带宽最容易成为瓶颈，单位成本也最高。

一个常见的错配：企业官网买了 8核16G，带宽只开 2M。服务器 CPU 利用率常年 5%，页面打开还是要等两秒，因为瓶颈在出口不在算力。反过来，纯静态博客用 1核2G 配 3M，打开速度比 4核8G 配 1M 还快。

CPU 和内存决定能跑多重的东西，带宽决定同时来多少人不会卡，系统盘决定能放多少数据，计费方式决定你最终掏多少钱。后面三节按这个顺序拆开讲。

## 带宽怎么算：一个公式顶过十篇经验帖

所需带宽（Mbps）≈ 峰值并发人数 × 平均页面大小（KB）÷ 128，再留一点余量。记住 1Mbps 大约等于 128KB/s，这个换算是所有带宽估算的基础。

按早年经验，网页平均 30KB，10 个人同时打开需要 300KB/s，3M 带宽刚好够。问题是现在的页面早就不是 30KB 了，带几张图、加载两三个脚本，随便就是几百 KB 到 1MB。同样 10 个并发，页面按 500KB 算，需要 5000KB/s，也就是 40M 带宽，账单立刻上一个台阶。

所以省钱的关键不是抠带宽，而是把图片、视频、下载包放到对象存储，前面套一层 CDN。源站只负责输出 HTML 和接口数据，2M 带宽也能撑住不错的访问量。这一步做不做，长期成本能差好几倍。

## 固定带宽还是按流量计费

访问集中在少数时段、平时几乎没有请求的站，按流量计费更划算；全天都有人访问的站，固定带宽更省。判断依据是带宽利用率，长期低于 10% 就选按流量。

按流量计费不用为闲置买单，代价是遇到刷流量或被爬虫扫站时费用不可控，固定带宽最多是被打满，不会额外扣钱。另外，轻量应用服务器这类套餐通常把带宽和月流量打包在一起，超出套餐流量后会限速或按量收费，买之前把流量包大小和超额规则看清楚，比对比 CPU 核数更有意义。

## 系统盘 40G 够不够，什么时候要加数据盘

40G 系统盘对绝大多数 Web 应用都够用。系统和程序本身占不到 10G，真正吃盘的是日志、备份和用户上传的文件。

系统盘只有一块，重装系统或更换镜像会清空里面的数据，这点和家用电脑的 C 盘一样。数据量小于 20G 时没必要单独买数据盘，把附件和数据库放在系统盘、定期打快照就行；附件增长快的论坛、电商，或者要跑独立数据库的业务，挂一块数据盘更稳妥，扩容和迁移都方便。

云盘类型上，性能排序大致是 ESSD 云盘 > SSD 云盘 > 高效云盘。普通网站选 ESSD 入门档够用，跑数据库这类对 IOPS 敏感的业务才需要往上加。

## 地域、操作系统和备案

地域选离用户最近的，延迟差别是实打实的。面向大陆用户就选大陆节点，但要做 ICP 备案；不想备案可以选香港或海外节点，代价是线路和延迟不如大陆。

操作系统按技术栈选。ASP、.NET、SQL Server 这套用 Windows Server；PHP、Python、MySQL 用 Linux，内存占用更小，同样 2G 内存能跑更多东西。Windows 本身比较吃内存，2G 配置跑 Windows Server 会相当紧张，这种情况要么加内存，要么换 Linux。

## 哪些配置你其实不需要

个人博客不需要 8 核，纯展示站不需要独享型实例，日访问几百的站也不需要 10M 带宽。真正该花钱的地方是带宽的可扩展性和磁盘的可靠性，不是核数。

还有一种常见浪费，是“为以后可能的高并发提前买”。云服务器能升配，与其现在买 16 核吃灰两年，不如把预算留到真有流量的时候。前提是你得接受升配价格不便宜这个事实。

更隐蔽的一种情况：CPU 打满不一定因为配置小，可能是数据库和网站挤在同一台机器上互相抢资源。这种先把数据库拆出去，比直接升到 8 核有效。

## 常见问题

**2核2G 的云服务器够用吗？**
够个人博客、企业展示站和日访问几千的站点用。同时跑数据库、应用和定时任务就会紧张，建议直接上 2核4G。

**1M 带宽能撑多少人同时访问？**
理论上一秒只能传出 128KB。一个 100KB 的页面勉强支撑一个并发，实际有缓存和 CDN 后能放大不少，但纯 1M 带宽只适合极轻量的站。

**云服务器买了之后能升级吗？**
能，CPU、内存、带宽一般都能在线升。但多数平台按原价补差，促销期一次买到位更划算。

**系统盘 40G 会不会不够？**
纯代码和系统占用很小，日志和附件才会把盘吃满。定期清理日志、把附件放对象存储，40G 能用很久。

**一定要买数据盘吗？**
数据量小于 20G 不用，快照可以保护系统盘里的数据。附件超过几十 G 再挂数据盘。

**香港服务器不用备案，是不是更省事？**
省事，但面向大陆用户时延迟和线路不如大陆节点。外贸站、测试环境、不想走备案流程的项目可以选，纯国内业务还是大陆节点更稳。
